세 seed의 SD는 동일 test 기간에 대한 학습 변동이다. 중첩 창을 독립 관측으로 가정한 통계량의 해석, 이미 개발 중 살펴본 test 기간, validation의 희소 vacuum 양성, 올바른 경보에 치우친 설명 cohort를 원고의 한계로 유지한다.

이번 배포 정리는 기존 run·가중치 파일과 미공개 원고를 제외한다. 모델 구현·라벨·분할 규칙과 문서에 기록된 결과 숫자를 바꾸지는 않는다. 과거 코드 감사의 모든 문제를 현재 미수정 결함으로 해석해서도 안 된다.
