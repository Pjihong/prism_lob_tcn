# 현재 한계와 확인 중인 사항

공개 자료를 정리하거나 테스트가 통과한 사실과 논문 결과의 과학적 재검증은 구분합니다.

| 항목 | 현재 한계 |
|---|---|
| FI-2010 변환 | 원 배포본의 어떤 파일·기간·행 선택으로 기대 CSV를 만들었는지 완전히 재현하는 변환 스크립트가 없음 |
| Vacuum 탐지표 | 원고와 저장된 평가 기록 사이의 출처·수치 일치를 아직 확정하지 못함 |
| 결과 재집계 | 기존 모델 가중치·결과 CSV·NPZ·상세 JSON은 비공개 보관하므로 이 공개판만으로 과거 표·곡선을 재집계할 수 없음 |
| Factorization 버전 | 원고 그림과 계산 기록을 같은 버전으로 지정하는 출처 확인이 남아 있음 |
| 비교 모델 선택 | 표의 각 행과 실제 사용된 baseline run의 식별을 확정해야 함 |
| CF 표본군 | 공개 mirror 그림의 deletion은 신뢰도 층화 정답 경보, insertion은 고신뢰 정답 경보로 동일 표본군이 아님 |
| 사례 갤러리 | 높은 신뢰도로 선택된 사례는 전체 예측 성능이나 일반적인 사례를 대표하지 않음 |
| 통계 해석 | 동일 test 기간의 seed 변동과 시장 표본의 불확실성은 다름. 중첩 창을 독립 표본으로 취급하지 않아야 함 |
| Kendall fallback | scipy가 없는 경로의 동률 처리가 tau-b와 다른 정의임. 설치 의존성에는 scipy가 포함됨 |
| 배포 조건 | 코드 라이선스·출판 DOI는 아직 선언하지 않았으며 데이터는 원 제공처 조건을 따라야 함 |

이미 개발 중 살펴본 test 기간, validation의 희소 vacuum 양성, 정답 경보 위주의 설명 표본 선택은 해석의 제한으로 남습니다. 이번 공개판은 이러한 문제를 해결했다고 주장하지 않습니다.
