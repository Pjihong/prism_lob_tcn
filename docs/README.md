자료 없이 시작하려면 테스트·합성 데모를 실행하거나 [그림 7개](../figures/README.md)를 열람하세요. 학습에는 입력 데이터, 학습된 모델의 개입·분석에는 호환 모델 파일이 필요합니다. 과거 수치 자료는 공개판에 포함하지 않습니다.

단위 테스트는 코드의 검사 대상 동작을, 그림 열람은 저장된 그림의 내용을 확인합니다. 어느 것도 논문 수치의 독립 재현을 뜻하지 않습니다.
