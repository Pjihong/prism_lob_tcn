# Prism-LOB 실행·재현 문서

이 문서는 논문을 읽고 **데이터를 준비하거나, 코드를 실행하거나, 표·그림의 근거를 확인하려는 독자**를 위한 안내입니다. 연구 동기와 방법론은 논문을 참고하고, 여기서는 실행에 필요한 정보와 결과 파일의 위치를 찾을 수 있습니다.

[저장소 소개](../README.ko.md) · [English overview](../README.md)

## 무엇을 확인하고 싶나요?

| 독자의 질문 | 읽을 문서 | 확인할 내용 |
|---|---|---|
| FI-2010은 어디서 구하고, 어떤 파일을 준비하나요? | [데이터 안내](DATA.md) | 원 논문·배포처, CSV 형식과 경로, 분할, 파일 해시, 변환 이력의 현재 한계 |
| 코드를 어떻게 설치하고 실행하나요? | [실행·재현 안내](REPRODUCE.md) | 데이터 없는 점검부터 학습·평가·귀속·개입 실험까지의 명령과 출력 위치 |
| 논문의 표와 그림은 어떤 코드와 결과 파일에 연결되나요? | [논문–코드 대응표](PAPER_MAP.md) | 표·그림별 실행 경로, 입력 자료, 결과 파일, 데이터 필요 여부 |
| 현재 재현할 때 주의해야 할 점은 무엇인가요? | [확인 중인 사항](KNOWN_ISSUES.md) | 결과 출처·수치 불일치, 데이터 변환 등 현재 재현에 영향을 주는 미해결 항목 |

## 목적에 따라 시작하기

### 데이터 없이 먼저 실행하기

[실행·재현 안내의 설치와 점검](REPRODUCE.md#1-설치와-데이터-없는-점검)부터 시작하세요. 단위 테스트와 모델 구조 점검을 실행할 수 있습니다. 기존 checkpoint 가중치는 포함하지 않으므로 적재·평가는 별도로 준비한 파일이 필요합니다. 완성된 그림은 [논문 PNG 목록](../figures/README.md)에서 바로 볼 수 있습니다. 기존 CF 원자료는 포함하지 않으므로 곡선 재집계에는 별도 입력이 필요합니다.

### 학습이나 새로운 실험 실행하기

[데이터 안내](DATA.md)에서 입력 CSV를 확인한 뒤, [논문용 학습 설정](REPRODUCE.md#4-논문용-학습-설정)을 사용하세요. 학습·검증, 테스트 평가, 귀속·개입 분석은 단계별 명령으로 구분되어 있습니다. 실행마다 seed와 출력 경로를 기록하면 기존 결과와 새 결과를 비교할 수 있습니다.

### 논문 결과의 근거 확인하기

[논문–코드 대응표](PAPER_MAP.md)에서 해당 표·그림을 찾으세요. [결과 경로 안내](../figures/README.md)와 [모델 해시 기록](../configs/paper/checkpoints.json)을 함께 보면 어떤 과제·seed·모델의 기록인지 확인할 수 있습니다.

## 결과와 검증 기록을 읽는 기준

| 자료 또는 점검 | 확인할 수 있는 것 |
|---|---|
| 단위 테스트·모델 적재 점검 | 검사 대상 코드와 checkpoint가 해당 환경에서 동작하는지 |
| 논문 PNG 열람 | 보관된 그림의 내용. 원 수치 재집계에는 별도 입력이 필요함 |
| 파일 SHA-256 검사 | 현재 파일이 기록된 파일과 바이트 단위로 일치하는지 |
| 데이터·설정·checkpoint를 지정한 새 평가 | 해당 입력과 모델에서 새로 계산한 예측·평가 결과 |

이 점검들은 서로 다른 단계를 확인합니다. 테스트 통과나 그림 재생성만으로 전체 학습과 논문 수치의 독립 재현이 완료된 것은 아닙니다. 현재 지원 범위와 미해결 사항은 [실행·재현 안내](REPRODUCE.md)와 [확인 중인 사항](KNOWN_ISSUES.md)을 기준으로 확인하세요.

## 독자가 먼저 볼 파일

```text
docs/
  README.md                    # 문서 읽는 순서
  DATA.md                      # 데이터 출처와 입력 형식
  REPRODUCE.md                 # 설치·실행·재현
  PAPER_MAP.md                 # 논문 표·그림과 코드·결과 연결
  KNOWN_ISSUES.md              # 현재 재현에 영향을 주는 미해결 사항
  PRESERVATION_MANIFEST.json   # 보관 파일과 변경·제외 기록의 해시 원장
  SOURCE_FILES.json            # 원본 자료의 파일 식별 정보
```

두 JSON 파일은 `python scripts/verify_preservation.py`가 사용하는 기계 판독용 자료입니다. 일반적인 실행에는 위 네 안내 문서만 읽으면 됩니다. 실험별 설정·예측·수치 자료는 [실험 기록 경로](../README.ko.md#실험-기록은-어디에-있나요)에 안내되어 있습니다.
